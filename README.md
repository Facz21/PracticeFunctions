# Práctica de Funciones en Python

Este repositorio contiene ejercicios prácticos para el manejo y aplicación de funciones en Python. El proyecto incluye un programa interactivo que demuestra el uso de funciones para realizar operaciones comunes como saludos, verificación de números pares, conversiones de temperatura y cálculos de área y perímetro de rectángulos.

## Características

- **Saludo personalizado**: Función para generar saludos con un nombre dado.
- **Verificación de paridad**: Función que determina si un número es par o impar.
- **Conversiones de temperatura**: Funciones para convertir entre grados Celsius y Fahrenheit.
- **Cálculos geométricos**: Funciones para calcular el área y el perímetro de un rectángulo.
- **Interfaz de menú**: Un sistema de menús interactivos para navegar entre las diferentes funcionalidades.

## Estructura del Proyecto

- `main.py`: Archivo principal que ejecuta el programa y maneja la lógica del menú.
- `source/functions.py`: Contiene las implementaciones de las funciones matemáticas y de utilidad.
- `gui/menu.py`: Contiene las funciones para mostrar menús y mensajes en la interfaz.

## Requisitos

- Python 3.x

## Cómo Ejecutar

1. Clona el repositorio:
   ```
   git clone https://github.com/tu-usuario/PracticeFunctions.git
   ```

2. Navega al directorio del proyecto:
   ```
   cd PracticeFunctions
   ```

3. Ejecuta el programa principal:
   ```
   python main.py
   ```

Sigue las instrucciones en pantalla para interactuar con el menú.
